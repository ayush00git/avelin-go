# PLAN: avelin-go v0.1

Unofficial Go client for the AVELIN API (https://api.avelin.ai). Standard library only, Go 1.22+.

## Scope (v0.1)
- `POST /v1/chat/completions` (OpenAI-style), plain and SSE streaming
- `POST /v1/messages` (Anthropic-style), plain and SSE streaming
- `GET /v1/models`, `POST /v1/embeddings`
- `GET /public/models.json` public catalog (no key), `go:generate` model constants, `cmd/avelin-models`
- Not yet: audio, images, TTS, `/v2` web endpoints (docs defer to Firecrawl for schemas), image input, embeddings `encoding_format`

## Layout
```
client.go      Client, options, Meta, request + retry plumbing
errors.go      APIError
stream.go      SSE decoder, Stream[T]
chat.go messages.go models.go embeddings.go
models_gen.go  generated by internal/genmodels from models.json
internal/mockapi   fixture-backed mock handler (tests + mock server)
cmd/avelin-models  live catalog table     cmd/mockserver  local mock
examples/{chat,stream,messages}      testdata/  JSON + SSE fixtures
```

## Public API
```go
func NewClient(opts ...Option) *Client   // key: AVELIN_API_KEY, base URL: AVELIN_BASE_URL or https://api.avelin.ai
WithAPIKey(string) WithBaseURL(string) WithHTTPClient(*http.Client) WithMaxRetries(int) WithTimeout(time.Duration)
(c) CreateChatCompletion(ctx, ChatCompletionRequest) (*ChatCompletion, error)
(c) CreateChatCompletionStream(ctx, ChatCompletionRequest) (*Stream[ChatCompletionChunk], error)
(c) CreateMessage(ctx, MessageRequest) (*Message, error)
(c) CreateMessageStream(ctx, MessageRequest) (*Stream[MessageStreamEvent], error)
(c) ListModels(ctx) (*ModelList, error)
(c) CreateEmbeddings(ctx, EmbeddingRequest) (*EmbeddingResponse, error)
(c) FetchCatalog(ctx) (*Catalog, error)                       // no key needed
Stream[T]: Next() bool, Current() T, Err() error, Close() error, Meta() Meta
APIError{StatusCode, Type, Code, Message, RequestID, Header, Body}
Results carry Meta{StatusCode, Header} and Raw json.RawMessage (full body, for undocumented fields).
```

## Assumptions (unconfirmed by AVELIN docs)
- Request ID header: none documented or observed. Client reads `x-request-id`, then `request-id`.
- `error.code` may be number or string: normalized to string.
- `thinking.budget_tokens` from Anthropic spec (mentioned only in a guide).
- A chat stream data payload with a top-level `error` object, and an Anthropic `error` event, end the stream with *APIError.
- Retry on 429 and 5xx only (documented); never on transport errors, never after a stream has started. Retry-After over 60s: no retry.
- Family column in `avelin-models` is derived from the ID: `avelin-<family>-<tier>`, and bare `avelin-<tier>` is the "intelligence" family per docs.
- Claim to verify: "Ultra models don't support reasoning_effort". Not found anywhere: docs mark all ultras as full reasoning and models.json lists `reasoning_effort` for all 9 models. No special-casing in code.
- Claim to verify: "models.json shows a multimodal family". It has no family field; "multimodal" does not appear in it.
